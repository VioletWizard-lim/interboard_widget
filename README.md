# 만능 칠판 위젯 (전자칠판용)

수업 시작 시 전자칠판 브라우저에 띄워 두고 쓰는 한 화면짜리 위젯입니다.
설치 없이 `index.html` 파일 하나만 열면 동작하며, 인터넷 연결도 필요 없습니다.

## 기능
| 위젯 | 설명 |
| --- | --- |
| 🔔 집중벨 | 종 아이콘 / "한 번"·"세 번" 버튼으로 종소리 + 집중 문구 |
| ⏱️ 타이머 | 1·2·3·5·10분 프리셋, ±1분·±10초 조절, 시작/멈춤/다시, 종료 시 종소리 3번 + 깜빡임 |
| 🎲 번호 뽑기 | 1~30번(인원수 조절 가능), 중복 없이 뽑기, 뽑은 번호 기록 |
| 👥 모둠 뽑기 | 2~8모둠, 중복 없이 뽑기, 뽑은 모둠 기록 |
| 📅 날짜 | 연도·월일·요일 |
| 🕘 시간 | 오전/오후 + 시:분:초 |
| 📝 오늘의 활동 | 구글 시트에 미리 쓰거나 ✏️ 편집으로 직접 입력 |
| ❓ 오늘의 질문 | 구글 시트에 미리 쓰거나 직접 입력, 🎲 버튼으로 다른 질문 |
| 💬 오늘의 명언 | 구글 시트에 미리 쓰거나 기본 명언이 날마다 바뀜, 🎲 버튼으로 다른 명언 |

- 오른쪽 아래에는 현재 시각이 항상 표시됩니다.
- **위젯을 누르면 화면 가득 확대**, 다시 누르면 원래 크기로 돌아옵니다. (버튼을 누를 때는 확대/축소되지 않습니다. `Esc` 키로도 닫을 수 있어요.)
- 오른쪽 위 **⛶ 전체화면** 버튼으로 브라우저 주소창까지 숨길 수 있습니다.

## 구글 시트로 미리 쓰기
집이나 휴대폰에서 활동·질문·명언을 미리 써 두면, 칠판이 인터넷으로 읽어 와서 그날 보여 줍니다.

1. 구글 시트를 만들고 첫 줄에 `날짜 · 활동 · 질문 · 명언 · 말한 사람`을 적습니다.
   (`미리쓰기-양식.csv`를 구글 시트에서 **파일 → 가져오기**로 불러와도 됩니다.)
2. 둘째 줄부터 씁니다.
   - **날짜를 적은 줄**은 그날 나옵니다. (`2026. 10. 7`, `10/7`, `10월 7일` 모두 됩니다)
   - **날짜를 비운 줄**은 수업 날마다 위에서부터 하나씩 차례로 나오고, 끝나면 처음으로 돌아갑니다.
   - 한 칸에 여러 줄을 쓰려면 `Alt + Enter`.
3. 시트의 **공유 → 링크가 있는 모든 사용자**로 바꾸고 **링크 복사**.
4. 칠판에서 오른쪽 위 **📋 미리 쓰기** → 링크(또는 시트 ID)를 붙여 넣고 **연결하기**. 칠판마다 처음 한 번만 하면 됩니다.

칠판은 켤 때, 30분마다, 날짜가 바뀔 때 시트를 새로 읽습니다. 인터넷이 끊기면 마지막으로 읽은 내용을 그대로 보여 줍니다.
칠판에서 ✏️ 편집이나 🎲로 바꾼 내용은 그날 하루만 우선합니다.

## 사용법
1. `index.html`을 크롬/엣지 또는 전자칠판 기본 브라우저로 엽니다.
2. 수업 시작 때 띄우려면 브라우저 시작 페이지(홈)로 이 파일을 지정해 두면 편합니다.
3. 소리는 브라우저 정책상 화면을 한 번 누른 뒤부터 재생됩니다.

## 안드로이드 전자칠판 앱 (APK)
`index.html`을 전체화면 앱으로 감싼 것입니다. 홈 화면에 "만능 칠판" 아이콘이 생기고, 수업 중에는 화면이 꺼지지 않습니다.
확대된 위젯이 있을 때 칠판의 **뒤로가기** 버튼을 누르면 원래 크기로 돌아갑니다.

### APK 받기
1. GitHub 저장소 → **Actions** 탭 → **Android APK** → 가장 최근의 초록색 ✔ 실행을 누릅니다.
2. 아래쪽 **Artifacts**의 `manneung-chalkpan-apk`를 내려받습니다. (zip 파일이에요)
3. 압축을 풀면 `manneung-chalkpan.apk`가 나옵니다.

`index.html`이나 `android/` 폴더를 고쳐서 올리면 APK가 자동으로 다시 만들어집니다.

### 칠판에 설치하기
1. APK를 USB에 담아 칠판에 꽂고, 칠판의 파일 관리자에서 엽니다.
2. "출처를 알 수 없는 앱" 설치를 허용하라는 안내가 나오면 허용합니다.
   (학교에서 설치를 막아 둔 칠판이면 관리자에게 문의하세요.)
3. 설치 후 홈 화면의 **만능 칠판** 아이콘을 누르면 됩니다.

### 직접 빌드하기 (선택)
Android Studio 또는 JDK 17과 Android SDK가 있으면 `android/` 폴더에서 `./gradlew assembleDebug`를 실행합니다.
