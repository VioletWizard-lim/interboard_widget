# 만능 칠판 위젯 (전자칠판용)

수업 시작 시 전자칠판 브라우저에 띄워 두고 쓰는 한 화면짜리 위젯입니다.
설치 없이 `index.html` 파일 하나만 열면 동작하며, 인터넷 연결도 필요 없습니다.

## 화면 배치 (Ver 2.0)
맨 위에 "○○○ 선생님과 함께하는 즐거운 ○○ 수업" 제목(이름·과목을 눌러서 바꿈), 오른쪽 위에 **미리 쓰기 · 설정 · 전체화면 · Ver** 버튼.

| 왼쪽 | 오른쪽 |
| --- | --- |
| ❓ 오늘의 질문 | ⏱️ 타이머 |
| 📝 오늘의 활동 (체크리스트) | 🏆 모둠 점수판 |

맨 아래 줄(테두리 없이 아이콘만): 🔔 집중벨 · 📅 날짜 · 🕘 시간 · 🙋 발표자 · 👥 발표모둠

**⚙️ 설정**에서 화면 스타일을 고릅니다: **알록달록**(기본, 위젯마다 다른 색) / **깔끔하게**(한 가지 색으로 통일).

## 기능
| 위젯 | 설명 |
| --- | --- |
| 📝 오늘의 활동 | 한 줄에 한 활동. 끝난 활동을 누르면 체크되고, 체크 안 한 첫 활동에 **"지금 하는 중"** 표시. 제목 옆에 "2/5 완료". 체크는 그날만 유지 |
| ⏱️ 타이머 | 1·2·3·5·10분, 크게 펼치면 ±1분·±10초. 끝나면 종소리 3번 + 깜빡임 |
| 🏆 모둠 점수판 | 모둠 칸을 누르면 +1, `−`로 −1, 1등에 👑. 초기화(두 번 누름) 전까지 유지. 모둠 수는 발표모둠과 같이 씀 |
| ❓ 오늘의 질문 | 구글 시트에 미리 쓰거나 직접 입력, 🎲로 다른 질문 |
| 🔔 집중벨 | 아이콘을 누르면 종소리. 크게 펼치면 한 번/세 번 |
| 🙋 발표자 / 👥 발표모둠 | 아이콘을 누르면 크게 펼쳐져서 뽑기. 인원·모둠 수, 중복 없이, 기록. 뽑은 결과는 아이콘 옆에 표시 |
| Ver 버튼 | 버전, 제작자, 업데이트 기록 |

- 아래 줄 아이콘은 **누르면 화면 가득 커지면서 세부 설정**이 나옵니다. 다시 누르거나 뒤로가기/`Esc`로 원래대로.
- 오른쪽 위 **⛶ 전체화면**(컴퓨터 브라우저용).

## 구글 시트로 미리 쓰기
집이나 휴대폰에서 선생님·과목·활동·질문을 미리 써 두면, 칠판이 인터넷으로 읽어 와서 그날 보여 줍니다.

1. 구글 시트를 만들고 첫 줄에 `날짜 · 선생님 · 과목 · 활동 · 질문`을 적습니다. (필요 없는 칸은 빼도 됩니다)
   - **선생님·과목**은 날짜 없는 줄에 한 번만 쓰면 제목에 매일 나오고, 날짜를 적은 줄에 쓰면 그날만 바뀝니다.
   (`미리쓰기-양식.csv`를 구글 시트에서 **파일 → 가져오기**로 불러와도 됩니다.)
2. 둘째 줄부터 씁니다.
   - **날짜를 적은 줄**은 그날 나옵니다. (`2026. 10. 7`, `10/7`, `10월 7일` 모두 됩니다)
   - **날짜를 비운 줄**은 수업 날마다 위에서부터 하나씩 차례로 나오고, 끝나면 처음으로 돌아갑니다.
   - 한 칸에 여러 줄을 쓰려면 `Alt + Enter`.
3. 시트의 **공유 → 링크가 있는 모든 사용자**로 바꾸고 **링크 복사**.
4. 칠판에서 오른쪽 위 **📋 미리 쓰기** → 링크(또는 시트 ID)를 붙여 넣고 **연결하기**. 칠판마다 처음 한 번만 하면 됩니다.

칠판은 켤 때, 30분마다, 날짜가 바뀔 때 시트를 새로 읽습니다. 인터넷이 끊기면 마지막으로 읽은 내용을 그대로 보여 줍니다.
칠판에서 ✏️ 편집이나 🎲로 바꾼 내용은 그날 하루만 우선합니다.

## 버전 올리기 (개발용)
기능을 바꾸면 `index.html`의 `APP_VERSION`을 올리고, 정보 창(`#about`)의 업데이트 기록에 한 줄 추가합니다. APK에는 GitHub Actions 빌드 번호가 자동으로 붙습니다.

## 사용법
1. `index.html`을 크롬/엣지 또는 전자칠판 기본 브라우저로 엽니다.
2. 수업 시작 때 띄우려면 브라우저 시작 페이지(홈)로 이 파일을 지정해 두면 편합니다.
3. 소리는 브라우저 정책상 화면을 한 번 누른 뒤부터 재생됩니다.

## 안드로이드 전자칠판 앱 (APK)
`index.html`을 전체화면 앱으로 감싼 것입니다. 홈 화면에 "만능 칠판" 아이콘이 생기고, 수업 중에는 화면이 꺼지지 않습니다.
확대된 위젯이 있을 때 칠판의 **뒤로가기** 버튼을 누르면 원래 크기로 돌아갑니다.

### APK 받기
1. GitHub 저장소 → **Actions** 탭 → **Android APK** → 가장 최근의 초록색 ✔ 실행을 누릅니다.
2. 아래쪽 **Artifacts**의 `manneung-chalkpan-apk`를 내려받습니다. (zip 파일이에요)
3. 압축을 풀면 `manneung-chalkpan.apk`가 나옵니다.

`index.html`이나 `android/` 폴더를 고쳐서 올리면 APK가 자동으로 다시 만들어집니다.

### 칠판에 설치하기
1. APK를 USB에 담아 칠판에 꽂고, 칠판의 파일 관리자에서 엽니다.
2. "출처를 알 수 없는 앱" 설치를 허용하라는 안내가 나오면 허용합니다.
   (학교에서 설치를 막아 둔 칠판이면 관리자에게 문의하세요.)
3. 설치 후 홈 화면의 **만능 칠판** 아이콘을 누르면 됩니다.

### 새 버전으로 업데이트할 때
APK는 만들 때마다 서명이 달라서 그냥 덮어 설치가 되지 않습니다.
1. 칠판에서 기존 **만능 칠판** 앱을 삭제합니다.
2. 새 APK를 설치합니다.
3. **📋 미리 쓰기**에서 구글 시트 링크를 다시 붙여 넣고 **연결하기**를 누릅니다.

미리 쓴 내용은 구글 시트에 있어서 그대로 남습니다. 칠판에서 ✏️로 고친 내용과 번호·모둠 설정만 처음 상태로 돌아갑니다.

### 직접 빌드하기 (선택)
Android Studio 또는 JDK 17과 Android SDK가 있으면 `android/` 폴더에서 `./gradlew assembleDebug`를 실행합니다.
